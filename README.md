# Algorithms 
 
Coursework and lab implementations for **Algorithms**, a compulsory 7.5 ECTS course in the Bachelor's Degree in Mathematics. 
## About the course
 
Algorithms covers the design, analysis, and implementation of fundamental algorithms and data structures, with an emphasis on efficiency and correctness. All exercises and lab assignments in this repository are implemented in **C++**. In this repository there are some of the programmes written by myself to answer problems presented in class using Jutge.org to submitt it. The "game" folder contains all the files for a strategy game presented by the lecturer, for which we had to program our own strategy and then test it and compete against our classmates. My strategy ended up ranked 6th out of 60 students aprox. 
 
## Topics covered
 
- **Cost of algorithms** — asymptotic notation, analysis of recursive and iterative algorithms, recurrences
- **Algorithmic techniques** — brute force, divide-and-conquer, greedy algorithms, dynamic programming
- **Basic data structures** — stacks, queues, priority queues, sets, and maps
- **Implementation of data structures** — heaps, hash tables, balanced search trees, MF-sets (union-find)
- **Graph algorithms** — representation, BFS/DFS and connectivity, shortest paths, minimum spanning trees
- **Computational complexity** — classes P, NP, and NP-hard; undecidability
